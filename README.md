# homebrew-tap

Homebrew formulae for [cerne](https://github.com/henriquesakata/cerne), living documentation for projects built with AI agents.

```bash
brew install henriquesakata/tap/cerne
```

Use the full name: since Homebrew 6.0 a third-party tap must be trusted, and installing by the full name trusts this formula in the same command. `brew upgrade cerne` updates it.

`Formula/cerne.rb` is written by cerne's release workflow on every tag (`scripts/homebrew-formula.sh`); do not edit it by hand.
